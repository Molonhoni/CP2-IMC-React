# Calculadora de IMC - React

Checkpoint desenvolvido para a disciplina de **Application Development**.

O projeto consiste em uma calculadora de IMC desenvolvida com **React + Vite**, utilizando componentes, estados com `useState` e estilização com CSS.

## Funcionalidades

- Cálculo do IMC com base no peso e altura informados;
- Classificação automática do resultado;
- Validação dos campos;
- Validação de valores inválidos;
- Exibição da situação atual do usuário;
- Cálculo da faixa de peso saudável para a altura informada;
- Destaque da classificação correspondente na tabela de IMC;
- Botão para limpar os campos;
- Botão para retornar à calculadora;
- Layout responsivo;
- Interface personalizada com novo esquema de cores e aparência.

## Tecnologias utilizadas

- React
- JavaScript
- CSS
- Vite

## Como executar o projeto

Clone o repositório:

git clone https://github.com/Molonhoni/CP2-IMC-React.git

Entre na pasta do projeto:

cd CP2-IMC-React

Instale as dependências:

npm install

Execute o projeto:

npm run dev

Depois, abra no navegador o endereço exibido pelo Vite.

## Build

Para gerar a versão de produção:

npm run build
